How Instasave works

A map of the classes, and the code that matters with notes in the margin. Pick a class on the map to see what it does and where to read it.

Two small helpers are used everywhere and left off the map: UiMotion, four short animations that are skipped when the system has animations turned off, and UserFacingException, an error that carries a string resource so it's shown in the phone's language.

Builds

Java 17, minimum Android 8.0, target SDK 34, and no third-party libraries: org.json ships with Android.

The debug build is app.instasave.debug, named Instasave Debug with its own icon, so it installs next to the release app with separate history and permissions. The release build is signed when keystore.properties exists in the project root.

./run-emulator.sh builds, starts an emulator, installs the debug app and opens it.
